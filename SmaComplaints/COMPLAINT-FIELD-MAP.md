# Complaint form coverage

Compared with SMA-FM-QM-05, Revision 07 (12 September 2025).

| Source form | Application location / treatment |
|---|---|
| Reference number | Generated complaint reference |
| Submitted by / complaint date | Part A; submitter comes from the signed-in account, date is editable |
| Customer name, hospital/lab, contact number, invoice/PO | Part A customer details; out-of-stock exception retained |
| Subject, part description, product code, category, serial/lot, expiry | Part A complaint/product details; expiry required for reagent/QC/calibrator |
| Frequency and detailed problem | Part A |
| Eight immediate-correction choices and Other description | Part A |
| Immediate action, responsible person, completion date, documented evidence | Part A repeating action rows; app also allows an extra due date |
| Received date, received by, received via | Part B; Fax and Email/letter are separate choices instead of the paper form's combined choice |
| Quality/non-quality, seriousness, hazard, urgency | Part B evaluation |
| Four reportability criteria | Part B yes/no answers |
| Reportable incident and reporting due date | QM reporting review; includes an additional basis-for-decision note |
| Root cause, investigator (By), investigation date | Part B investigation |
| Planned action item, responsible person, due date | Part B action plan |
| Completed action, objective evidence, responsible person, completion date | Part B completion; links to the approved plan |
| HOD and QM plan/completion approval name/date/signature | Signed-in account identity, decision timestamp and audit trail; no handwritten signature-image input |
| Response-over-one-week reason, owner and HOD approval | Exception request and HOD decision; identities/times captured in audit |
| Extension reason, owner and HOD approval | Extension request, requested due date and HOD decision; identities/times captured in audit |
| Effectiveness action, responsible, due/completion dates, documented evidence | Part C repeating checks |
| QM reviewer and CM approver name/date/signature | Authenticated QM/CM decisions and audit timestamps; no handwritten signature-image input |

Digital identity/timestamps replace paper name/date/signature entries. This is an application audit trail, not a qualified digital-signature or signature-image feature. Supporting files are uploaded on the Evidence tab. Up to 30 action rows can be entered rather than the paper form's three printed rows.

To create a complaint, sign in as Requestor (or choose Requestor in the development preview) and use **New complaint**. Approver roles keep their approval permissions.
