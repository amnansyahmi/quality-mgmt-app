# Additional document-processing components

- [PdfPig 0.1.16](https://github.com/UglyToad/PdfPig): Apache-2.0; PDF text extraction.
- [PDFtoImage 5.4.0](https://github.com/sungaila/PDFtoImage): MIT; PDFium/SkiaSharp rendering. Retain the transitive components' notices.
- [Tesseract .NET 5.2.0](https://github.com/charlesw/tesseract): Apache-2.0; native Tesseract/Leptonica components retain their upstream licenses.
- [English tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast): Apache-2.0; OcrData includes the model and LICENSE.txt.
- Dashboard Chart.js 4.6.1: MIT; license is in wwwroot/vendor/chart.js/LICENSE.md.
- [Inter](https://github.com/rsms/inter) variable font via @fontsource-variable/inter 5.3.0: SIL Open Font License 1.1; license is in wwwroot/vendor/inter/LICENSE.txt.
- [Lucide](https://lucide.dev) icon paths via lucide-static 1.62.0: ISC; generated into Services/Icons.g.cs by scripts/build-icons.mjs.

Pinned dependencies are captured in packages.lock.json. Retain upstream notices when redistributing native binaries.
